Custom & edge cases

Actions, custom HTML messages, bare messages, dedupe, stacking overflow, and bulk clear. Actions can carry a timer too — actions and timerStyle/duration are fully independent of each other. The HTML message also has its own progress-bar/countdown timer, and marks exactly where the countdown lands with a [data-notify-countdown] placeholder — anything after that marker in the HTML renders after the countdown.

Element ids & notification id tracking

Every part of a toast gets a stable, unique DOM id for CSS/JS targeting (notify-toast-<id>, notify-message-<id>, notify-close-<id>, …). Every notify.*() call also returns that notification's id, and onClose(id, reason) / the global close event report that exact same id back — so you always know which toast opened or closed.
